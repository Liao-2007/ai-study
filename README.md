# ai-study

一个面向人工智能专业本科生的中文学习技能。上传一页教材、一道题或一段代码截图，就可以从原文出发复习，适用于人工智能基础、概率论、离散数学、数据结构和计算机组成原理等课程。

## 怎么用

在支持 Agent Skills 的工具中载入本仓库的 `SKILL.md`，保留 `agents/` 和 `assets/` 目录。调用 `ai-study` 时附上学习材料，说明你想弄懂哪一步，或者希望怎样自测。

例如，上传折半查找的教材截图后，可以这样问：

> 用 ai-study 带我逐轮执行这段代码。选一个目标值刚好在数组末尾的例子，列出每轮的 low、high 和 mid，再解释循环条件怎样影响最后一个元素。最后出一道改错题，等我作答后再给解析。

如果要复习整节，可以要求先总结重点，再出两道综合题，并把答案、推导过程和分步评分标准放在最后。附上老师给的考试范围时，技能会据此判断考试价值；只有教材时，会标明哪些判断仍待核实。
